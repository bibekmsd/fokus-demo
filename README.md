## 🏗 Architecture

Fokus follows the MVC (Model-View-Controller) architecture pattern.

```
lib/
├── models/
├── controllers/
├── views/
│   ├── screens/
│   └── widgets/
├── services/
├── routes/
├── utils/
└── main.dart
```
